LEVEL 1 — BASIC STAR PATTERNS
☐ 01. Solid Square                    -> [ // Loops(2) | Outer(i<n) | Inner(j<n) | * ]
☐ 02. Hollow Square                   -> [ // Outer(i<n) → if(First/Last)-> n*(loop) : else (*+(n-2)S+*) ]
->                                          [ // Outer(i<n) | Inner(j<n) | Border? * : Space ]

☐ 03. Left Half Pyramid               -> [ // Outer(i<n) → Inner(j<=i) → *]
☐ 04. Inverted Left Half Pyramid      -> [ // Outer(0->i<n) → Star(0-><n-i) ]
☐ 05. Right Half Pyramid              -> [ // Outer(0 -> i<n) → Space(0 -> < n-i-1) → Star(0-><= i) ]
☐ 06. Inverted Right Half Pyramid     -> [ // Outer(0->i<n) → Space(0-><n-i-1) → Star(0-><=i) ]

LEVEL 2 — NUMBER PATTERNS
☐ 07. Increasing Number Triangle      -> [ // Outer(0->i<n) → Number(0-><=i) → Print(j+1) ]
☐ 08. Repeated Number Triangle        -> [ // Outer(0->i<n) → Number(0-><=i) → Print(i+1) ]
☐ 09. Reverse Number Triangle         -> [ // Outer(0->i<n) → Number(0-><n-i) → Print(j+1) ]
☐ 10. Binary Triangle                 -> [ // Outer(0->i<n) → Number(0-><=i) → Print((i+j)%2)]
☐ 11. Floyd's Triangle                -> [ // Outer(0->i<n) → Inner(0-><=i) → Print(count++)]
☐ 12. Number Crown                    -> [ // Outer(i<n) → Left(j=0-><=i, j+1) → Space(2*(n-i-1)) → Right(j=i->>=0, j+1) ]

LEVEL 3 — ALPHABET PATTERNS
☐ 13. Alphabet Triangle               -> [ // Outer(0->i<n) → Alphabet(0-><=i) → Print('A'+j) ]
☐ 14. Reverse Alphabet Triangle       -> [ // Outer(0->i<n) → Alphabet(0-><n-i) → Print('A'+j) ]
☐ 15. Repeated Alphabet Triangle      -> [ // Outer(0->i<n) → Alphabet(0-><=i) → Print('A'+i) ]
☐ 16. Alphabet Palindrome Pyramid     -> [ // Outer(0->i<n) → Space(0-><n-i-1) → Left(0-><=i,'A'+j) → Right(i-1->>=0,'A'+j)]
☐ 17. Reverse Alphabet Staircase      -> [ // Outer(0->i<n) → Space(0-><n-i-1) → Alphabet(0-><=i,'A'+(n-i-1)+j) ]

LEVEL 4 — PYRAMID PATTERNS
☐ 18. Full Pyramid                    -> [ // Outer(0->i<n) → Space(0-><n-i-1) → Star(0-><2*i+1) ]
☐ 19. Inverted Full Pyramid           -> [ // Outer(0->i<n) → Space(0-><i) → Star(0-><2*(n-i)-1) ]
☐ 20. Diamond                         -> [ // Outer(0->i<2*n-1) → Row(i<n?i:2*n-i-2) → Space(0-><n-row-1) → Star(0-><2*row+1) ]
☐ 21. Half Diamond                    -> [ // Outer(0->i<2*n-1) → Row(i<n?i:2*n-i-2) → Star(0-><=row) ]

LEVEL 5 — HOLLOW PATTERNS
☐ 22. Hollow Pyramid                  -> [ // Outer(0->i<n) → Space(0-><n-i-1) → Star(0-><2*i+1) → Print('*' if i==n-1 || j==0 || j==2*i else ' ') ]
☐ 23. Hollow Inverted Pyramid         -> [ // Outer(0->i<n) → Space(0-><i) → Star(0-><2*(n-i)-1) → Print('*' if i==0 || j==0 || j==2*(n-i)-2 else ' ') ]
☐ 24. Hollow Diamond                  -> [ // Outer(0->i<2*n-1) → Row(i<n?i:2*n-i-2) → Space(0-><n-row-1) → Star(0-><2*row+1) → Print('*' if j==0 || j==2*row else ' ') ]
☐ 25. Hollow Rhombus                  -> [ // Outer(0->i<n) → Space(0-><n-i-1) → Star(0-><n) → Print('*' if i==0 || i==n-1 || j==0 || j==n-1 else ' ') ]
☐ 26. Hollow Rectangle                -> [ // Outer(0->i<n) → Star(0-><n) → Print('*' if i==0 || i==n-1 || j==0 || j==n-1 else ' ') ]

LEVEL 6 — BUTTERFLY PATTERNS

☐ 28. Solid Butterfly                 -> [ // Outer(0->i<2*n-1) → Row(i<n?i:2*n-i-2) → Left(0-><=row) → Space(2*(n-row-1)) → Right(0-><=row) ]

LEVEL 7 — MATHEMATICAL PATTERNS
